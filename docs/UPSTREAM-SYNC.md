## Shader-contract changes (pack compatibility)

Upstream changed the Iris 'vx' contract in five places since the merge-base; the fork is at contract version 0 (bare `#define VOXY`). (1) 13230c27: `#define VOXY 1` (IrisShaderPatch.SHADER_DEFINE_VERSION). Packs feature-gate with `#if VOXY >= N`; against the fork's empty macro that is a preprocessor error → newer BSL/Complementary/Luster voxy patches can hard-fail. MUST adopt before alpha (value 1). (2) eda60134: SHADER_DEFINE_VERSION 2 + voxy.json `skipShaderDepthHackFix`. Unless a pack opts out, upstream now writes depth=1.0 (far) where stencil==0 (MC-covered pixels) before handing LOD depth to the pack's translucent/composite stages, so packs no longer see the 0.0 mask value. Packs targeting ≥2 assume this. This is the same symptom class the fork fought in rounds 10-16 (BSL water SSR reflectionMask stamp / raytrace far-plane poisoning → VxSsrMaskFix, VxFogCap, abyss fill). Adopt after alpha: implement on GL (cherry-pick) AND in MetalVxRenderPipeline (depth write where stencil==0 before the translucent copy), then bump to 2 and A/B whether VOXY_VX_SSR_MASK_FIX can be retired. Do NOT emit 2 before the Metal side exists — BSL v10.1.3 (the fork's verified pack) predates it and does not need it, but a pack that checks ≥2 would then get the old 0-depth behaviour under the new promise. (3) upstream/dev 534d58ec (2026-09-14, not in 12111): SHADER_DEFINE_VERSION 3 + `useDynamicFarPlane` piped to shaders — the far plane becomes dynamic; packs on 3 may read a new uniform. Investigate once a pack in the wild requires it; not needed for BSL/Luster today. (4) d33bb92c + a780bd72 + d78cef44 + 75078880: shared lod/lighting.glsl getLightmapUv = clamp(base*(15/16)+0.5/16, 8/256, 248/256) (final form) used by BOTH the vanilla path and the PATCHED_SHADER path, so VoxyFragmentParameters.lightmap handed to voxy_emitFragment shifts by roughly +0.03125 (texel-centre sampling). Visual: LODs under BSL/Luster get slightly brighter and match vanilla LOD brightness. The fork's quads.frag getLightmap() (:103) lacks the offset and its :259 comment relies on the 8/256 floor as an emitter sentinel — keep the sentinel, ship behind a kill switch, A/B day/night at the LOD boundary. Adopt (after alpha) for parity; not required for pack compatibility. (5) 68f782d6/76392ab0/08a17128/5779f52d/449be6d2: pack TAA becomes opt-in — taaFunction is null when the pack has no voxy_taa.glsl (fork still compiles a `{return vec2(0.0);}` stub for every pack), and when present the jitter is applied to the occlusion-cull boxes and the HiZ traversal so TAA-jittered terrain is not culled against un-jittered boxes (edge flicker under shader TAA). Iris UBO binding point moves 5→7; screenspace.glsl globals renamed _minBB/_maxBB/_frustumCulled/_screenSize to avoid collisions with pack includes. Check whether BSL v10.1.3 / Luster ship voxy_taa.glsl: if yes, this batch matters for TAA edge flicker; if no, it is harmless parity. Metal caveat: the TAA UBO must be bound in the compute encoder and binding 7 checked against MetalVxRenderPipeline. (6) Removals: 13160430 drops the default-off DH-impersonation samplers/uniforms (dhDepthTex*, DISTANT_HORIZONS define) — no pack the fork targets uses them; 8dfb77d9 stops Voxy adding colortex16..19 because Iris ≥1.10.5 has 32 render targets natively — fork builds on Iris 1.10.7 so the mixin is redundant. (7) Sampler/lightmap fixes that packs observe indirectly: a7dc2112 (voxy depth samplers become MIPPED_NEAREST_NEAREST — linear filtering of depth gave packs garbage), d0e879b6 (Iris 'lightmap' external sampler was a dead fixed texture id after MC recreated the lightmap), 4b8d7039 (glBindSampler(unit,0) so an Iris-bound sampler object cannot force linear depth filtering). Adopt the first two before alpha. Net for pack compatibility: before alpha = VOXY 1 + sampler fixes; after alpha = depth-hack v2 + lighting UV + TAA opt-in; v3 dynamic far plane = watch upstream/dev.
