=== DESIGN SUMMARY ===
Two-phase Metal adapter design for Voxy's native vx Iris contract. PHASE B ("contract lite") keeps the existing Metal LOD render + IOSurface bridges and adds, GL-side at the proven SOLID-head hook: (1) a D32F depth side-channel (VxIrisSideChannel) that decodes the packed depth bridge into real vxDepthTexOpaque/vxDepthTexTrans textures served through a VoxySamplers fallback supplier, (2) a colour injector (VxContractInjector) that writes pre-lit-but-unfogged LOD colour into the pack's voxy.json opaqueDrawBuffers colortexes (BSL/CR: colortex0+6) with NO depth attachment — zero depthtex0 writes, matching both packs' excludeLodsFromVanillaDepth=true — and (3) a Metal fragment permutation that strips the screen-final defines (USE_ENV_FOG etc.) so the pack's deferred1 vxZ<1 branch is the only fog/shadow/AO pass. VOXY define + vx* matrix uniforms already reach packs on Metal unconditionally (MixinStandardMacros/MixinMatrixUniforms have zero backend gates) — Phase B only has to make vxZ real. PHASE C ("full contract") turns the Metal LOD pass into a 3-plane BGRA8 material g-buffer (sampledColour / tinting / nibble-packed lightmap+face+16-bit customId) written by a host-provided voxy_emitFragment MRT emitter under PATCHED_SHADER, exported through per-plane IOSurface bridges (opaque + translucent sets, dual depth export), then resolved GL-side by MetalVxResolvePass: a #version 410 fullscreen program assembled from [regenerated binding-free header from IrisVoxyRenderPipelineData's StructLayout/sampler map + VoxyFragmentParameters struct + decode main() with a gl_FragCoord.z shim + the pack's pre-expanded voxy_opaque/voxy_translucent patch text], drawing into FBOs built from pipeData.opaque/translucentDrawTargets with the pack's voxy.json blending closure, writing vxDepthTex* as the FBO depth attachments via gl_FragDepth. Java-only MRT plumbing (GraphicsPipelineDesc int[] formats; MetalRenderBackend loop; zero native changes). Riskiest bets and their cheapest on-device probes: Phase B = constant-depth disc probe (~15 lines, one relaunch) after a zero-code fog-far check; Phase C = compile-only probe (VOXY_VX_RESOLVE_COMPILE_TEST=1) that assembles+links both resolve programs at pack load and dumps logs before any rendering work is built. BSL vs Complementary differences are entirely data-driven (translucentDrawBuffers [16,1] vs [0]; FSH vs FRAGMENT_SHADER guard is irrelevant because patch text arrives pre-expanded).
