# Stress-test plan — Metal path (branch `feature/lod-shadows-perf-stress`)
Generated 2026-09-25 from a code audit of the Metal path (Voxy on Apple Silicon, MC 1.21.11, Sodium 0.8.1, Iris 1.10.7 + BSL). Each scenario names the in-game steps, the exact env line, the pass criteria and what to grep in `run/logs/latest.log`. The user drives the client; scenarios are ordered cheapest-and-highest-yield first. Keep an RSS sampler running for every scenario that mentions memory:
```bash
while true; do date +%T; ps -o rss= -p $(pgrep -f "net.minecraft.client.main.Main"); sleep 30; done | tee /tmp/rss.txt
```
## Scenarios
### S1 Baseline static soak (10 min) — establishes fps/memory/flicker reference
**Steps.** Join, stand still on a hill overlooking ocean+forest at noon/clear, do not touch the mouse for 10 min. Sample process RSS every 30 s from a second terminal: `while true; do date +%T; ps -o rss= -p $(pgrep -f 'net.minecraft.client.main.Main') ; sleep 30; done | tee /tmp/rss-s1.txt` (values in KB).
**Run.**
```bash
VOXY_QUICKPLAY="<world>" VOXY_FORCE_METAL=1 VOXY_FRAME_TIMING=1 VOXY_DEBUG_CMD="5:time set noon;6:weather clear;7:gamemode creative" VOXY_AUTO_SCREENSHOT=60 ./gradlew runClient
```
**Pass.** [Metal-LayerB] fps within ±10% across all windows after the first 2; [Metal-FLICKER] min==max and changes==0 for every window after warmup; RSS plateau (last 5 samples within 5%); no hs_err_pid in run/; no 'composite disabled'/'inject failed' lines.
**Grep.**
```bash
grep -E 'Metal-LayerB|Metal-FLICKER|Metal-TIMING|Metal-DIAG' run/logs/latest.log ; grep -Ei 'disabled|inject failed|incomplete|status=' run/logs/latest.log ; ls run/hs_err* 2>/dev/null
```
